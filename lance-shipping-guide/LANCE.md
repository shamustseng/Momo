# Lance（徐銓霈）— 出貨助理

## 背景（Shamus 告訴我的）
- 阿爾法餐飲（Alpha，broth-master.com）創新事業部新招聘的「小天使」：30 歲男性，有一點點、不嚴重的身心障礙。負責協助電商出貨。
- Shamus 的原話：「這個關係到一個身心障礙孩子的工作信心，希望你非常認真的面對這次的工作。」目標是讓他「出貨更順利、更有信心」。
- Shamus 要求給他的東西要「比較給他正面情緒價值」。

## 我從他的文件與回饋看到的樣子
- 他自己把整套 momo 出貨流程整理成文件（SCM 看單 → Lark 報表 → 印單解鎖 → NetSuite 銷售訂單 → 愛上／希塔倉出貨 → NS 交貨），內容相對完整，還附了截圖。這套流程是他的，工具上標「流程整理：Lance」。
- 他的回饋（第二份 docx）非常準確、具體、有主見：
  - 不要逐項打勾，要「一個固定流程，就不怕忘記」。
  - 看訂單一律照順序：超商 → 第三方常溫 → 第三方冷凍。
  - 會質疑不必要的功能（「今日訂單」的目的是什麼？不確定是否必要）。
  - 補上別人沒寫的細節：7-11／全家集運的固定收件資料、週四希塔倉聯絡人換成王傳斌、套公式前要點兩下確認。
  - 不懂的會直說（「第 7 步不確定怎麼操作」），也會列出自己還沒有答案的問題。
- 結論：他是一個懂自己工作、需要固定順序與明確完成條件的成年同事，不是需要被哄的人。

## 對他說話／為他設計的原則
- 語氣：平實、尊重、對成年同事說話。肯定要落在具體事實上（做到了什麼、在截單前完成），不誇張、不用兒語、不用 emoji 當獎勵。
- 結構：固定順序的編號流程，每一步有「什麼時候算做完」；一次只看一步；要打字的內容幫他組好可複製。
- 卡住時的原則（寫在 App 側欄）：不確定就先停下來問、問人是把貨出對、做錯了越早說越好。
- 隱私：他的個資只保留名字，密碼類只放流程必需的 MOMO PDF 密碼。
