# MOMO 渠道談判測算器

單一 HTML 檔案（`index.html`），無需安裝任何套件，直接以瀏覽器開啟即可使用。

## 背景

依據《MOMO 渠道合作深化與行銷提案報告》（2026/08/11）：向 MOMO 爭取將平台抽成自
26.5% 調降至 10.0%，差額 16.5% 以 1:1 比例回投聯合行銷，並假設下半年度業績每月成長
1.5 倍。本工具將報告中的測算模型重建為可互動調整的計算機，並補上原報告沒有的部分：

- **談判論點**：計算「損益兩平成長率」——業績成長需達到多少，MOMO 在新方案下收到的
  抽成金額才不會低於「維持現狀、業績不變」的情境，並生成可直接貼入提案的摘要文字。
- **敏感度分析**：不同月成長率假設下的累計結果，說明目前 1.5 倍假設的安全邊際。
- **實際成效追蹤**：合作啟動後逐月回填實際業績與實際行銷投入，自動計算達成率與邊際
  ROAS，用以驗證「行銷投入 ↔ 業績成長」的關係、作為續談籌碼。
- **毛利與行銷投入平衡點**：以阿爾法餐飲整體毛利率（0%–15% 可調）估算毛利額，對比投入
  MOMO 渠道的行銷預算，算出打平所需毛利率、現行毛利率下可承受的回投比例上限，避免業績
  翻倍的同時實際上是虧本衝量。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊，或 `python3 -m http.server` 後於瀏覽器開啟）。
2. 在「假設設定」調整基期業績、抽成、回投比例、成長假設等參數，所有區塊會即時重算。
3. 每月談判/合作有實績後，於「實際追蹤」表格輸入實際銷售額與實際行銷投入。
4. 所有輸入（假設與實際數據）會自動保存在瀏覽器 `localStorage`，重新整理不會遺失。

## 檔案

- `index.html` — 完整工具（HTML + CSS + JavaScript，無外部依賴）。

# MOMO 出貨單產生器（`shipping/`）

把 momo 供應商後台匯出的**訂單清單**（每列一個商品品項）整理成可以直接列印的**出貨單 Excel**，
一張出貨單一頁，版面對齊 momo 後台的「裝箱明細」。純前端單頁工具，資料不會離開你的電腦。

## 使用方式

1. 用瀏覽器開啟 `shipping/index.html`（雙擊即可；所需函式庫已放在 `shipping/vendor/`，離線可用）。
2. **匯入**：把後台匯出的 `.xlsx / .xls / .csv` 拖進頁面，或直接貼上從後台網頁複製的表格。
   第一次可以按「載入範例試用」或「下載範例檔」（`shipping/sample/momo訂單匯出範例.xlsx`，內容為虛構資料）。
   **有密碼保護的檔案**會自動用「momo 檔案密碼」欄位的密碼解鎖（預設 `90754866MOMO`，可修改並會記住）；
   密碼不對會再詢問一次。解鎖在瀏覽器內完成，支援 Office 標準／Agile 加密的 xlsx 與 RC4／XOR 加密的舊版 xls。
3. **對應欄位**：程式依欄名自動對應「訂單編號、出貨單號、配送編號、收件人、商品名稱、數量…」等 19 個欄位，
   必要欄位為訂單編號／收件人／商品名稱／數量。若後台欄名不同可手動指定，對應結果會記住，同格式檔案下次自動套用。
4. **篩選**：依「訂單／出貨狀態」勾選要出貨的狀態（已出貨、取消、退貨等預設不勾）、依配送方式、關鍵字過濾，
   也可以逐張取消勾選。點任一列可展開該張出貨單的商品明細。
   先前已匯出過的出貨單號會標示「已匯出過」並預設排除，避免重複出貨。
5. **匯出**：設定供應商名稱、出貨單標題、印單日期、排序後按「匯出出貨單 Excel」。
   也可以按「直接用瀏覽器列印」，不經 Excel 直接印出一張一張的出貨單。

## 匯出的 Excel 內容

| 工作表 | 內容 |
| --- | --- |
| 出貨總表 | 類似 momo「到廠取貨總表」：NO、宅配單號、訂單編號、出貨單號、收件人、電話、地址、品項數、數量、代收款、最晚出貨日、商品摘要，含合計列與篩選。 |
| 揀貨彙總 | 各商品編碼的總出貨數量與涉及的出貨單數，方便倉庫一次備貨。 |
| 出貨單 | 每張出貨單一頁（A4 直式、自動分頁）：印單日期、標題、訂單編號、出貨單號、配送編號、最晚出貨日、收件人、電話、地址，商品表格（序號／商品編碼／商品名稱／國際條碼／數量／商品原廠編號／檢查框）、合計、備註、注意事項。可改為「每張出貨單一個工作表」。 |
| 原始明細 | 對應整理後的逐列資料，附來源列號，方便核對。 |

## 檔案

- `shipping/MOMO出貨單產生器.html` — **單一檔案版**，函式庫與範例檔已內嵌，下載這一個檔案雙擊即可使用（離線可用）。
- `shipping/index.html` — 開發用原始版本（HTML + CSS + JavaScript），搭配 `vendor/` 與 `sample/` 使用。
- `shipping/build-standalone.js` — 執行 `node shipping/build-standalone.js` 重新產生單一檔案版。
- `shipping/vendor/xlsx.full.min.js` — SheetJS 0.18.5，讀取 xlsx / xls / csv / 貼上表格。
- `shipping/vendor/exceljs.min.js` — ExcelJS 4.4.0，輸出含格式、分頁與列印設定的 Excel。
- `shipping/vendor/officecrypto.browser.js` — officecrypto-tool 0.0.19 瀏覽器版，解開密碼保護的 Excel；由 `shipping/tools/officecrypto/build.sh` 打包。
- `shipping/sample/momo訂單匯出範例.xlsx` — 範例輸入檔（虛構資料）。
