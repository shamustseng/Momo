# MOMO 渠道談判測算器

單一 HTML 檔案（`index.html`），無需安裝任何套件，直接以瀏覽器開啟即可使用。

## 背景

依據《MOMO 渠道合作深化與行銷提案報告》（2026/08/11）：向 MOMO 爭取將平台抽成自
26.5% 調降至 10.0%，差額 16.5% 以 1:1 比例回投聯合行銷，並假設下半年度業績每月成長
1.5 倍。本工具將報告中的測算模型重建為可互動調整的計算機，並補上原報告沒有的部分：

- **談判論點**：計算「損益兩平成長率」——業績成長需達到多少，MOMO 在新方案下收到的
  抽成金額才不會低於「維持現狀、業績不變」的情境，並生成可直接貼入提案的摘要文字。
- **敏感度分析**：不同月成長率假設下的累計結果，說明目前 1.5 倍假設的安全邊際。
- **實際成效追蹤**：合作啟動後逐月回填實際業績與實際行銷投入，自動計算達成率與邊際
  ROAS，用以驗證「行銷投入 ↔ 業績成長」的關係、作為續談籌碼。
- **毛利與行銷投入平衡點**：以阿爾法餐飲整體毛利率（0%–15% 可調）估算毛利額，對比投入
  MOMO 渠道的行銷預算，算出打平所需毛利率、現行毛利率下可承受的回投比例上限，避免業績
  翻倍的同時實際上是虧本衝量。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊，或 `python3 -m http.server` 後於瀏覽器開啟）。
2. 在「假設設定」調整基期業績、抽成、回投比例、成長假設等參數，所有區塊會即時重算。
3. 每月談判/合作有實績後，於「實際追蹤」表格輸入實際銷售額與實際行銷投入。
4. 所有輸入（假設與實際數據）會自動保存在瀏覽器 `localStorage`，重新整理不會遺失。

## 檔案

- `index.html` — 完整工具（HTML + CSS + JavaScript，無外部依賴）。

# 雞湯大叔全聯損益測算器

單一 HTML 檔案（`pxmart-soup/index.html`），直接以瀏覽器開啟。算「雞湯大叔常溫湯包兩支（花膠＋干貝）上架全聯，最後整體賺多少」。

- **數字來源**：《雞湯大叔_兩支18000_常溫_V7》。預設值重現 V7：18,000／支 100% 售罄含稅淨利 742,532、未稅 707,173；損益兩平 82.46%；資金峰值 (2,888,570) 於 2026/11/1。
- **可調參數**：各支交貨量、破損備量、成本、DM 費；均價（直接輸入，或以 $179／$169／$149 價格帶占比加權）；進價率、物流／前進倉／德明服務費率；進倉、逆物流；行銷、DM 檔數、檢驗、印刷版費；額外費用（可一鍵帶入簡報行銷預算）；貨款第一段與回款比例。
- **輸出**：售罄率滑桿下的整體淨利（未稅／含稅切換）、V7 格式四情境損益表、單支拆解、月度現金流與資金峰值、售罄率×均價敏感度、每支 13k–25k 規模比較。
- **實際結算**：上傳實際生產（品項、生產量、破損、交貨、單位成本）、銷售（月份、品項、銷量、售價或銷售額、退貨）、費用（項目、類別、金額）資料，格式可為 Excel、CSV、Word、PowerPoint、PDF 或照片。有表格的檔案（含 Word／PowerPoint／PDF 內的表格）依欄位名稱直接匯入；沒有表格的（掃描 PDF、單據照片、文字說明）在線上版交給 Claude 判讀，結果先列出供確認再寫入。PDF、圖片、CSV 原檔另存供查核。之後算出「至今」與「若現在結案」的實際淨利，逐行對照 V7 同售罄率預估。欄位名稱自動辨識，一本 Excel 的多個工作表會自動分類；銷售明細匯入時按月份＋品項＋售價彙總。有上傳的費用類別用實際金額，沒上傳的沿用參數。發佈成 artifact 時資料存在共享資料庫（同事看到同一份）；直接開本機檔案時存在瀏覽器 localStorage。
- 通路費拆解：V7 每包 20.46576（含稅）＝售價×4.5%×1.05＋進價×4%×1.05＋進價×6%×1.05，改售價時同步變動。
