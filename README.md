# MOMO 渠道談判測算器

單一 HTML 檔案（`index.html`），無需安裝任何套件，直接以瀏覽器開啟即可使用。

## 背景

依據《MOMO 渠道合作深化與行銷提案報告》（2026/08/11）：向 MOMO 爭取將平台抽成自
26.5% 調降至 10.0%，差額 16.5% 以 1:1 比例回投聯合行銷，並假設下半年度業績每月成長
1.5 倍。本工具將報告中的測算模型重建為可互動調整的計算機，並補上原報告沒有的部分：

- **談判論點**：計算「損益兩平成長率」——業績成長需達到多少，MOMO 在新方案下收到的
  抽成金額才不會低於「維持現狀、業績不變」的情境，並生成可直接貼入提案的摘要文字。
- **敏感度分析**：不同月成長率假設下的累計結果，說明目前 1.5 倍假設的安全邊際。
- **實際成效追蹤**：合作啟動後逐月回填實際業績與實際行銷投入，自動計算達成率與邊際
  ROAS，用以驗證「行銷投入 ↔ 業績成長」的關係、作為續談籌碼。
- **毛利與行銷投入平衡點**：以阿爾法餐飲整體毛利率（0%–15% 可調）估算毛利額，對比投入
  MOMO 渠道的行銷預算，算出打平所需毛利率、現行毛利率下可承受的回投比例上限，避免業績
  翻倍的同時實際上是虧本衝量。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊，或 `python3 -m http.server` 後於瀏覽器開啟）。
2. 在「假設設定」調整基期業績、抽成、回投比例、成長假設等參數，所有區塊會即時重算。
3. 每月談判/合作有實績後，於「實際追蹤」表格輸入實際銷售額與實際行銷投入。
4. 所有輸入（假設與實際數據）會自動保存在瀏覽器 `localStorage`，重新整理不會遺失。

## 檔案

- `index.html` — 完整工具（HTML + CSS + JavaScript，無外部依賴）。

# MOMO／Cyberbiz 出貨單產生器（`shipping/`）

同一套程式支援兩個平台，打包成兩個單一 HTML：`MOMO出貨單產生器.html` 與 `Cyberbiz出貨單產生器.html`。
把 momo SCM 下載的出貨文件（PDF）或訂單清單（Excel／Word），或 Cyberbiz 後台匯出的訂單檔，整理成可以直接列印的**出貨單 Excel**，
並依出貨 SOP 一次產出「新零售銷售報表」列、「NS 銷售訂單」打單清單、「愛上出貨」建單資料與給倉庫的回報訊息。
純前端單頁工具，資料與密碼都不會離開你的電腦。

## 使用方式

1. 用瀏覽器開啟 `shipping/MOMO出貨單產生器.html` 或 `shipping/Cyberbiz出貨單產生器.html`（單一檔案版，雙擊即可、離線可用），或開發版 `shipping/index.html`（加 `?platform=cyberbiz` 切換平台）。
2. **匯入**：把檔案拖進頁面，可一次多個，支援：
   - **momo PDF**：第三方「列印明細」（裝箱明細）、「列印宅配單」、「列印出貨總表」。程式自動辨識三種版面並依出貨單號／宅配單號合併：
     明細給品項、宅配單給完整地址／電話／發票號碼／溫層、總表給材積與件數。只有宅配單沒有明細的出貨單會標「缺列印明細」。
   - **Excel 各格式**：xlsx／xlsm／xlsb／xls／ods／csv／tsv（每列一個商品品項，進入欄位對應）。
   - **Cyberbiz 後台 PDF**：「訂單明細」（orders_print_details）、「出貨明細」（fulfillments_details）、「揀貨訂單」（picking_lists）與黑貓快速到店「託運單」（ezcat）會自動辨識並依訂單編號（#1253）合併：訂單明細給商品／規格／單價／小計／訂購人／發票／訂單日期，出貨明細給收件人／電話／地址／門市／配送方式／託運單號，託運單給配送編號與溫層。「黑貓快速到店」視為宅配流程（愛上出貨平台 cyberbiz-cat）。
   - **Cyberbiz 匯出檔**：欄名自動對應（訂單編號、訂單成立時間、訂單狀態、付款狀態、配送方式、配送狀態、物流單號、顧客姓名、收件人、收件地址、超商門市／店號、商品名稱、商品選項、SKU、數量、商品單價／小計、顧客備註）；「依訂單」匯出時一格多品項（換行分隔、`x 數量`）會自動拆成多列；超商取貨會把門市名稱與店號當地址；欄名含「單價」自動視為單價、否則視為該列合計。付款狀態可篩選（未付款、已退款預設不勾）。
   - **Word docx**：有表格就當訂單清單對應欄位；內文若是貼上的 momo 裝箱明細文字也會解析。
   - **zip 壓縮包**：自動展開裡面的 Excel／PDF／Word。
   - **有密碼的檔案**：PDF、Excel、Word 都會自動用「momo 檔案密碼」欄位的密碼解鎖（預設 `90754866MOMO`，可修改並會記住），
     密碼不對會再詢問。也可以直接貼上從後台網頁複製的表格。
   - 第一次可按「載入範例：momo 三份 PDF」或「載入範例：訂單清單 Excel」（`shipping/sample/`，內容為虛構資料）。
3. **商品資料**：程式內建 Lance 表B（商品成本）與表C（倉庫、品牌、NS 品號、溫層）的商品資料表，依出貨品名關鍵字自動對應簡稱、倉別、Brand、NS 代碼、溫層與商品成本，不必上傳。
   成本或倉別變動時，在匯出區「內建商品資料表」直接改（一行一品，欄位以 | 分隔），會記在瀏覽器；也可上傳商品品號清單 Excel 覆蓋。
4. **對應欄位**（只有表格類來源需要）：依欄名自動對應 20 個欄位，必要欄位為訂單編號／收件人／商品名稱／數量。
5. **篩選**：依訂單狀態（已出貨、取消等預設不勾）、配送方式、出貨倉別、關鍵字過濾，也可逐張取消勾選。
   同發票號碼或同收件人＋地址的出貨單會標「可併箱」；先前匯出過的出貨單號會標「已匯出過」並預設排除。
6. **匯出**：按「匯出 Excel」，檔名為 (通路)(月日)_(出貨方式)_(溫層)_(倉別)，例 MOMO0904_宅配_常溫_愛上，超商不分溫層例 MOMO0904_711（Chrome／Edge 會跳出另存視窗；其他瀏覽器自動下載，頁面下方另有「點此另存」備援連結），或「直接用瀏覽器列印出貨單」。頁面下方有回報訊息預覽，可一鍵複製貼到 Lark／LINE。
   依 Lance 回饋，出貨總表、揀貨彙總、出貨單三個工作表預設不產生，需要時在匯出區勾選；NS 銷售訂單已移除（不再由本組處理）。

## 匯出的 Excel 內容

| 工作表 | 內容 |
| --- | --- |
| 出貨總表 | 類似 momo「到廠取貨總表」：宅配單號、訂單編號、出貨單號、收件人、電話、地址、溫層、品項數、數量、代收款、材積、倉別、發票號碼、商品摘要，含合計列。 |
| 揀貨彙總 | 各商品編碼的總出貨數量、Brand、倉別與涉及的出貨單數。 |
| 出貨單 | 每張一頁（A4 直式自動分頁），版面對齊 momo 裝箱明細，另帶電話、地址、材積、發票號碼。可改為每張一個工作表。 |
| 新零售銷售報表 | 欄位 A–W，依 Lance「ai訂單轉換」v4（momo／cyberbiz 各一份）：出貨倉別依表C（愛上倉紅底、希塔倉藍底，贈品不填不上色）；客戶代號依表D；月份 yyyymm；Brand（售價 0 填「贈品」）；Channel 由檔名或 PDF 判斷；order_create_date 格式「16-SEP」（momo 用發票日期、cyberbiz 用訂單日期）；平台訂單號完整；**料號**＝表C NS 品號；品項＝簡稱；數量＝平台數量×入數；售價/單價 0.1 位、未稅 0.001 位、總金額含稅／未稅整數、進價(未稅) 0.001 位、總進價收入(未稅) 0.01 位、含稅整數（cyberbiz 無進價欄則留空）；商品成本依表B，總未稅＝成本×數量，總含稅＝×1.05。 |
| 愛上出貨 | 依表E：平台（有宅配單號＝momo-cat／cyberbiz-cat，沒有＝momo／cyberbiz；超商＝momo7-11超取／momo全家超取）、方案名稱、數量、廠商原始訂編＝訂單編號(前14碼)-Channel-宅配／711／全家、訂購人只寫姓名（需宅配單 PDF 才有完整姓名）、收件人／電話／地址（超商固定為大智通電子商務組／日翊物流）、付款「無(已付款)」、發票「否」、客戶&宅配單備註（冷凍→送達前請先致電；青花椒辣醬、茶油剝皮辣椒→易碎）、內部&系統備註（1.請使用第三方支配單；易碎貼標；蛤蜊雞湯、打拋摃丸檢查破損；超商件週二、四加 40 件集運提醒）、託運單號。 |
| 回報訊息（希塔出貨） | 表F 格式：第一行 @湯恩齊 Keith（出貨日為週四則 @王傳斌，可覆寫），「您好，以下是momo要出貨的訂單，再麻煩您協助」，接著把含希塔倉商品的每張出貨單裡「每一排」都寫成「商品*數量」，不合併、包含贈品；不寫銷售訂單號。 |
| 原始明細 | 整理後逐列資料（含發票、材積、Brand、倉別、NS 代碼、價格與來源檔），方便核對。 |

## 檔案

- `shipping/MOMO出貨單產生器.html`、`shipping/Cyberbiz出貨單產生器.html` — **單一檔案版**，所有函式庫與範例檔已內嵌，下載一個檔案雙擊即可使用（離線可用）。Cyberbiz 版預設不帶密碼、Channel＝Cyberbiz、NS 客戶＝官網(Cyberbiz)、愛上平台＝Cyberbiz-宅配／Cyberbiz-超商取貨，這些都可在「打單資料參數」修改。
- `shipping/index.html` — 開發用原始版本，搭配 `vendor/` 與 `sample/` 使用。
- `shipping/build-standalone.js` — 執行 `node shipping/build-standalone.js` 一次重新產生兩個平台的單一檔案版。
- `shipping/vendor/` — SheetJS 0.18.5（讀 Excel／CSV）、ExcelJS 4.4.0（輸出 Excel）、pdf.js 4.10（讀 PDF）、mammoth 1.8（讀 Word）、
  JSZip 3.10（解壓縮）、officecrypto-tool 0.0.19 瀏覽器版（解開加密 Office 檔；由 `shipping/tools/officecrypto/build.sh` 打包，
  pdf.js 由 `shipping/tools/build-pdfjs.sh` 打包）。
- `shipping/sample/` — 範例輸入檔（虛構資料）：momo 三份 PDF、momo 訂單清單 Excel、Cyberbiz 訂單匯出 Excel、訂單清單 Word。
