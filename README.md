# 每日戰情

單一 HTML 檔（`daily-sales/每日戰情.html`），不用安裝任何東西，雙擊用瀏覽器開就能用。
拿來回答一個問題：**這次檔期到底有沒有把業績拉起來。**

## 使用方式

1. 從《2026 零售商品進度表》下載最新檔（要含「2026 銷售紀錄」工作表）。
2. 開啟 `每日戰情.html`，按右上角 **更新資料** 選那個檔案，或直接把檔案拖進視窗。
   數字會在瀏覽器裡重算，並記在 `localStorage`，下次開啟不用重選。
3. 按 **一鍵輸出**：

   | 選項 | 用途 |
   | --- | --- |
   | 下載 CSV（Excel） | 每日明細，含 BOM，Excel 開不會亂碼 |
   | 下載單檔網頁 | 把當下的頁面連資料打包成一個 HTML，寄給別的部門直接點開 |
   | 下載 Markdown | 貼進報告或 Notion |
   | 複製表格 | TSV，直接貼進 Excel／Google 試算表會自動分欄 |
   | 複製戰情摘要 | 四行文字，貼進 LINE 群或信件 |

**檔期起算日**在「每日明細」上方可直接改，換雙 11 或別的檔期不用改程式，選了會記住。

## 口徑

- **momo**＝銷售紀錄裡 `MOMO`（供應商出貨）＋ `MOMO寄倉`；**官網**＝`官網`；其餘（團購主／
  直播主、全家、ASO、美聯社、企業採購…）歸「其他通路」，不進兩個主指標。
- **銷售額**＝消費者付的含稅金額；**實收**＝公司入帳的未稅金額（momo 算進價收入，官網算
  售價未稅），兩者差額是給 momo 的通路價差。
- **件數**不含贈品；運費歸在「其他通路」。
- 日期採 `order_create_date`（訂單建立日），不是出貨日或入帳日。
- momo 偶有幾筆沒填進價，用同品項的進價率回推補值，補了幾筆會寫在頁面下方。

## 讀檔的兩個坑（改程式前先看）

這份進度表是 Google 試算表匯出的 xlsx，有兩個地方一般的讀檔函式庫會踩雷，
`每日戰情.html` 裡都處理掉了：

1. **金額欄幾乎都是公式，而且檔案沒有存快取值。** 所以不能直接讀值，要自己算。
   再加上 Excel 會把整欄相同的公式存成「共用公式」（這份檔案有 4,340 個），
   只有第一格寫得出算式；SheetJS 不會展開。頁面裡用瀏覽器內建的 `DecompressionStream`
   自己解開 xlsx（xlsx 就是 zip），讀原始 XML 把共用公式還原成每一格的算式再求值。
2. **訂單編號是做成超連結的 rich text**，SheetJS 會讀成空字串，所以另外自己解
   `sharedStrings.xml` 補回來。不補的話訂單數會少算。

沒網路時 SheetJS 載不進來，這時在 Excel 或 Google 試算表把「2026 銷售紀錄」
另存成 CSV 再丟進頁面，一樣可以算（CSV 的金額已經是算好的值，更單純）。

## 資料不進版控

`daily-sales/.gitignore` 擋掉 `*.xlsx` / `*.csv` 等檔案。repo 裡的 `每日戰情.html`
是**不含任何數字的空白版**，第一次開會請你選檔案。要給人一份已經有數字的，
用「下載單檔網頁」產生，不要 commit 進來。

# MOMO 渠道談判測算器

單一 HTML 檔案（`index.html`），無需安裝任何套件，直接以瀏覽器開啟即可使用。

## 背景

依據《MOMO 渠道合作深化與行銷提案報告》（2026/08/11）：向 MOMO 爭取將平台抽成自
26.5% 調降至 10.0%，差額 16.5% 以 1:1 比例回投聯合行銷，並假設下半年度業績每月成長
1.5 倍。本工具將報告中的測算模型重建為可互動調整的計算機，並補上原報告沒有的部分：

- **談判論點**：計算「損益兩平成長率」——業績成長需達到多少，MOMO 在新方案下收到的
  抽成金額才不會低於「維持現狀、業績不變」的情境，並生成可直接貼入提案的摘要文字。
- **敏感度分析**：不同月成長率假設下的累計結果，說明目前 1.5 倍假設的安全邊際。
- **實際成效追蹤**：合作啟動後逐月回填實際業績與實際行銷投入，自動計算達成率與邊際
  ROAS，用以驗證「行銷投入 ↔ 業績成長」的關係、作為續談籌碼。
- **毛利與行銷投入平衡點**：以阿爾法餐飲整體毛利率（0%–15% 可調）估算毛利額，對比投入
  MOMO 渠道的行銷預算，算出打平所需毛利率、現行毛利率下可承受的回投比例上限，避免業績
  翻倍的同時實際上是虧本衝量。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊，或 `python3 -m http.server` 後於瀏覽器開啟）。
2. 在「假設設定」調整基期業績、抽成、回投比例、成長假設等參數，所有區塊會即時重算。
3. 每月談判/合作有實績後，於「實際追蹤」表格輸入實際銷售額與實際行銷投入。
4. 所有輸入（假設與實際數據）會自動保存在瀏覽器 `localStorage`，重新整理不會遺失。

## 檔案

- `index.html` — 完整工具（HTML + CSS + JavaScript，無外部依賴）。
