# MOMO 渠道工具

兩個獨立的單一 HTML 檔案，無需安裝任何套件，直接以瀏覽器開啟即可使用：

- `index.html` — **MOMO 渠道談判測算器**（抽成調整與行銷效益追蹤）
- `order-check.html` — **訂單出貨核對**（每日核單與月報表）

---

# MOMO 渠道談判測算器（`index.html`）

## 背景

依據《MOMO 渠道合作深化與行銷提案報告》（2026/08/11）：向 MOMO 爭取將平台抽成自
26.5% 調降至 10.0%，差額 16.5% 以 1:1 比例回投聯合行銷，並假設下半年度業績每月成長
1.5 倍。本工具將報告中的測算模型重建為可互動調整的計算機，並補上原報告沒有的部分：

- **談判論點**：計算「損益兩平成長率」——業績成長需達到多少，MOMO 在新方案下收到的
  抽成金額才不會低於「維持現狀、業績不變」的情境，並生成可直接貼入提案的摘要文字。
- **敏感度分析**：不同月成長率假設下的累計結果，說明目前 1.5 倍假設的安全邊際。
- **實際成效追蹤**：合作啟動後逐月回填實際業績與實際行銷投入，自動計算達成率與邊際
  ROAS，用以驗證「行銷投入 ↔ 業績成長」的關係、作為續談籌碼。
- **毛利與行銷投入平衡點**：以阿爾法餐飲整體毛利率（0%–15% 可調）估算毛利額，對比投入
  MOMO 渠道的行銷預算，算出打平所需毛利率、現行毛利率下可承受的回投比例上限，避免業績
  翻倍的同時實際上是虧本衝量。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊，或 `python3 -m http.server` 後於瀏覽器開啟）。
2. 在「假設設定」調整基期業績、抽成、回投比例、成長假設等參數，所有區塊會即時重算。
3. 每月談判/合作有實績後，於「實際追蹤」表格輸入實際銷售額與實際行銷投入。
4. 所有輸入（假設與實際數據）會自動保存在瀏覽器 `localStorage`，重新整理不會遺失。

## 檔案

- `index.html` — 完整工具（HTML + CSS + JavaScript，無外部依賴）。

# 訂單出貨核對（`order-check.html`）

每天上傳兩份檔案，逐張比對「該出的貨」與「實際出的貨」，月底輸出當月出貨報表。

## 解決什麼問題

打單出貨後，最常見的錯誤是收件資訊被改動、數量出錯、漏出貨、或出了不該出的單。這些
錯誤在客訴進來之前不會有人發現。本工具在出貨當下就把差異挑出來。

## 使用方式

1. 用瀏覽器開啟 `order-check.html`（雙擊即可）。
2. **當天全部訂單**：放後台匯出的當日訂單檔（應該要出貨的清單）。
3. **實際出貨明細**：放打完出貨單後的檔案。
4. 確認欄位對應（系統會自動辨識，辨識錯的用下拉選單改）。
5. 按「開始核對」，檢視差異；點任一列可展開，逐欄比對訂單檔與出貨檔。
6. 按「存為當日紀錄」，資料歸入該日期。
7. 月底到「月報表」選月份，匯出 CSV。

## 核對內容

以**訂單編號**為對應依據，同一張單有多列明細會自動合併計算，比對：

| 項目 | 說明 |
| --- | --- |
| 收件人 | 忽略空白與全形半形差異 |
| 電話 | 預設只比後 9 碼，`+886`、`(02)`、`-` 等格式差異不誤判 |
| 地址 | 預設寬鬆比對，忽略空白、全形半形、臺／台、郵遞區號、樓／F |
| 數量 | 整張單加總，或逐項商品比對；可設容差 |
| 金額 | 整張單加總；可設容差（四捨五入誤差可填 1） |

結果分四種狀態：**正確**、**資料不符**（欄位有出入）、**未出貨**（訂單有、出貨檔沒有）、
**多出貨**（出貨檔有、訂單沒有）。

## 檔案格式

- 支援 `.xlsx`、`.csv`、`.tsv`，或直接從 Excel 複製整片區域貼上。
- CSV 自動判斷 UTF-8 / Big5 / UTF-16 編碼與逗號／分號／Tab 分隔。
- 舊版 `.xls` 不支援，請先另存成 `.xlsx` 或 CSV。
- 標題列不在第一列（前面有說明列）會自動判斷，也可手動指定。
- 兩份檔案的欄位名稱不用一樣，各自對應一次即可；同樣格式的檔案下次會自動記住對應。

## 資料存放

- Excel 解析、比對、報表全部在瀏覽器內完成，**檔案不會上傳到任何地方**，也不需要連網。
- 每日紀錄存在瀏覽器 `localStorage`。換電腦或清瀏覽器資料會消失，請定期用「備份全部
  紀錄（JSON）」匯出。
- 為控制容量，每日紀錄只保存彙總數字與**異常明細**，核對正確的單不逐張留存。

## 輸出

- 差異清單 CSV／完整核對表 CSV（當日）
- 當月報表 CSV：逐日出貨張數、數量、金額、異常張數、正確率，含合計列
- 當月異常明細 CSV
- 全部月份彙總 CSV
- 列印／存 PDF

CSV 皆含 UTF-8 BOM，用 Excel 直接開不會亂碼。
