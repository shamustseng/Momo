# MOMO 渠道談判測算器

單一 HTML 檔案（`index.html`），無需安裝任何套件，直接以瀏覽器開啟即可使用。

## 背景

依據《MOMO 渠道合作深化與行銷提案報告》（2026/08/11）：向 MOMO 爭取將平台抽成自
26.5% 調降至 10.0%，差額 16.5% 以 1:1 比例回投聯合行銷，並假設下半年度業績每月成長
1.5 倍。本工具將報告中的測算模型重建為可互動調整的計算機，並補上原報告沒有的部分：

- **談判論點**：計算「損益兩平成長率」——業績成長需達到多少，MOMO 在新方案下收到的
  抽成金額才不會低於「維持現狀、業績不變」的情境，並生成可直接貼入提案的摘要文字。
- **敏感度分析**：不同月成長率假設下的累計結果，說明目前 1.5 倍假設的安全邊際。
- **實際成效追蹤**：合作啟動後逐月回填實際業績與實際行銷投入，自動計算達成率與邊際
  ROAS，用以驗證「行銷投入 ↔ 業績成長」的關係、作為續談籌碼。
- **毛利與行銷投入平衡點**：以阿爾法餐飲整體毛利率（0%–15% 可調）估算毛利額，對比投入
  MOMO 渠道的行銷預算，算出打平所需毛利率、現行毛利率下可承受的回投比例上限，避免業績
  翻倍的同時實際上是虧本衝量。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊，或 `python3 -m http.server` 後於瀏覽器開啟）。
2. 在「假設設定」調整基期業績、抽成、回投比例、成長假設等參數，所有區塊會即時重算。
3. 每月談判/合作有實績後，於「實際追蹤」表格輸入實際銷售額與實際行銷投入。
4. 所有輸入（假設與實際數據）會自動保存在瀏覽器 `localStorage`，重新整理不會遺失。

## 檔案

- `index.html` — 完整工具（HTML + CSS + JavaScript，無外部依賴）。

# 雞湯大叔聯名權利金測算器

單一 HTML 檔案（`royalty-calculator.html`），直接以瀏覽器開啟即可使用。

## 背景

依三份合約重建「雞湯大叔 × 龍鳳 × 娘娘駕到」聯名案的兩段金流：

- 《聯名合作備忘錄 MOU》（2026/08/06）：旗山龍鳳按出廠價（NT$90 含稅／包）2% 付產品授權金
  給阿爾法（希塔食品／雞湯大叔），月結；肖像權授權金 NT$25,000 由龍鳳付，阿爾法代收代付。
- 《雞湯大叔×泰國娘娘聯名商品合作案 合作合約書》（2026/07/10）：娘娘團隊分潤原則為阿爾法
  可分配收益的 40%，季結。
- 《商品附約：泰Chill 打拋豬煎餃（龍鳳水餃）》（2026/07/10）：龍鳳通路銷售按出廠價 0.8%
  付娘娘；阿爾法自售每包 NT$1.5；娘娘導流訂單另按成交金額 3% 付導購分潤。

## 功能

- 輸入銷售包數、龍鳳／阿爾法通路比例、導流訂單金額，即時算出龍鳳應付阿爾法的授權金、
  阿爾法應付娘娘的分潤，以及阿爾法淨留金額。
- 可切換含稅／未稅出廠價計價、授權金是否計入阿爾法自售包數，比較解讀差異。
- 每包拆解、銷量敏感度、結算時程與條款原文對照。
- 第二個分頁「麻辣香菜蛋餃」（洽談中，尚未簽約）：出貨價暫定 59 元（8 粒裝，100 克／盒）、成本 32 元、目標 20,000 盒，
  阿爾法抽 5% 權利金，撈王總公司分走其中 25%；撈王不收一次性權利金，也沒有未售庫存處理費。含每盒拆解、銷量與價格敏感度，
  以及與煎餃案的每單位比較。
- 第三個分頁「全家 鮮食聯名」（已簽約）：依《合作協議書》阿爾法餐飲 × 全家便利商店，合作期間
  115/09/01–116/08/31，全家按鮮食聯名商品總實銷金額 0.5% 給付獎勵金，無第三方分潤。附件三的
  七支商品售價與上市日已預填，販售天數預設 60 天、每店日均 0.3 個，可逐品項估算銷量或直接輸入
  實銷金額，並列出四期結算與入帳時程。
- 所有輸入自動保存在瀏覽器 `localStorage`。
